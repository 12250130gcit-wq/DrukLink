# DrukLink Product Backlog Items

## PBI-01 — User registration and login
As a user, I want to create an account and log in so that I can use DrukLink.

## PBI-02 — User profile
As a user, I want to create and edit my profile so that others can understand my professional background.

## PBI-03 — Skills and portfolio
As a job seeker, I want to add skills and portfolio items so that employers can evaluate my abilities.

## PBI-04 — Job posting
As a job giver, I want to post a job so that job seekers can discover opportunities.

## PBI-05 — Job application
As a job seeker, I want to apply for a job so that I can be considered for an opportunity.

## PBI-06 — Messaging
As a user, I want to send messages so that job seekers and employers can communicate.

## PBI-07 — Notifications
As a user, I want notifications so that I know when important activity happens.

## PBI-08 — Verification
As a platform user, I want account verification so that DrukLink is more trustworthy.

## PBI-09 — Usability testing
As the project team, I want to test the prototype with users so that we can identify usability problems before the final version.
